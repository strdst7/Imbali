## 📖 About The Project

**IMBALI** is a dual-purpose interactive web application. For readers, it is an immersive, sensory digital storybook featuring original South African folktales—including *"Nomvula & The Weaver of Starlight"* and *"Thandi and the Rain Kudu"*. For digital creators, it doubles as an end-to-end **YouTube Visual Storytelling Studio**, equipped with timecoded teleprompters, B-roll AI prompt generators, and SEO metadata exporters.

---

## ✨ Key Features

### 🎨 1. Flagship AI Key Art & Interactive Hotspot Inspector
* **16:9 Widescreen Canvas:** Features bespoke AI artwork depicting the Drakensberg escarpment at sunset (`hero-keyart.jpg` & `rain-kudu-hero.jpg`).
* **Interactive Lore Pins:** Clickable hotspots on the painting reveal Zulu/San cultural origins, mythological symbolism, and the exact AI generation prompts used.
* **Traditional Call-and-Response Opener:** Click *“Shout ‘COSI!’ to Open the Tale”* to trigger an authentic African story circle chime and visual celebratory burst.
* **YouTube 4K Thumbnail Mode:** Live toggle that frames the artwork with high-CTR YouTube thumbnail title overlays.

### 🦁 2. Folklore Characters & *Izaga / Maele* Proverb Carousel
Explore rich character lore and traditional wisdom across South African languages:
* **Nomvula of the Carved Reed:** A Zulu woodcarver whose patience and empathy unlock the painted cave.
* **Nhlava the Honeyguide:** The sacred whistling trickster bird who guides those with generous hearts.
* **Mavungula, Weaver of Starlight:** An ancient celestial orb-spider spinning sunset mist in an 800-year-old baobab tree.
* **Khanyisa, The Thunder-Bull:** The San Rain-Animal (*!Khwa*) who steps out of the ochre rock art wall.
* **Proverb Carousel:** Interactive audio-supported proverbs in **isiZulu, isiXhosa, /Xam San lore, and Sesotho**.

### 🎙️ 3. 3-Act Folktale Reader & Spoken Voice-Over Narrator
* **Sensory Atmosphere Tri-Bar:** Dynamic indicators highlighting the sights, sounds, and scents of each scene as you scroll.
* **Live Web Audio Narration:** Built-in browser voice synthesizer with adjustable pacing:
  * `0.85x` – *Fireside Storyteller*
  * `0.95x` – *Normal Pacing*
  * `1.10x` – *Dynamic Reading*
* **Editorial Reading Controls:** Adjustable text scaling (`--story-scale`), chapter navigation, native sharing, and an **Ubuntu Moral Plaque**:
  > *"Umuntu ngumuntu ngabantu — A single thread breaks in the wind; woven together, we hold the sky."*

### 🎬 4. YouTube Channel Creator Production Studio
Built specifically for folklore and faceless YouTube automation channels:
* **Timecoded Voiceover Teleprompter:** Full `00:00` to `12:00` script broken down into *Cold Open Hook, Acts I–III, and Outro CTA*, complete with Ken Burns camera movement notes and SFX cues.
* **One-Click Metadata Exporter:** Copy high-CTR video titles, formatted descriptions with clickable timestamps, video tags, and pinned comments.
* **AI Prompt & Biome Generator:** Customize heroes, mythical creatures, and South African biomes (*Drakensberg, Blyde River Canyon, Kalahari Red Dunes, Wild Coast*) to generate instant Midjourney v6 and DALL·E 3 prompts.

## 🛠️ Technical Architecture

* **Frontend Framework:** React 18 + TypeScript + Vite
* **Styling & Design System:** Tailwind CSS with custom editorial typography (`Georgia` display serif paired with `Inter` sans-serif) and warm earth-tone palettes (`#f3ecdd`, `#bd542f`, `#3b3028`).
* **Animations:** Custom CSS keyframe animations (`hero-breathe`, `rise-in`, `line-pulse`) with full accessibility compliance (`prefers-reduced-motion: reduce` support).
* **Audio Engine:** Native HTML5 Web Speech API for zero-latency voice synthesis and ambient chime sound effects.

## 🚀 Getting Started

To run the IMBALI storytelling studio locally on your machine:

### Prerequisites
* [Node.js](https://nodejs.org/) (v18+ recommended)
* `npm`, `yarn`, or `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/imbali-storytelling-studio.git
   cd imbali-storytelling-studio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for Production:**
   ```bash
   npm run build
   ```
